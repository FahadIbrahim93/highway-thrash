# Highway Thrash — Game Design Document (Summary)

## Vision
Spiritual successor to **Road Rash** (1991–96) fused with the endless traffic-dodging loop of **Traffic Racer / Traffic Rider**.

## Core Loop
1. Select bike in garage → Endless run
2. Weave traffic, near-miss for multiplier, attack rivals
3. Pick up club/chain for heavier hits
4. Crash → tumble recovery + invulnerability
5. Cash + reputation → unlock/upgrade bikes

## Tech
TypeScript, Three.js, React, Vite, PWA, adaptive quality, offline-ready.
